## Important business distinctions

The project is positioned as restaurant SaaS but does not implement commerce, billing, orders, payments, per-table sessions or automatic scanning/reconstruction. Restaurant status controls are real access restrictions; storage-derived tier labels are descriptive only. Menus are “direct-link” rather than confidential: public published URLs and assets remain accessible to anyone who has the address. Private menu mode removes dish entries from API output and is separate from private concierge storage. No feature is marked PLANNED merely because a historical comment or marketing sentence mentions it.
